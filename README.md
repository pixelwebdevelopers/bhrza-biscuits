==================================================

Create a premium Pakistani food/FMCG website rather than a generic corporate website.

The design should feel:
- Modern
- Fresh
- Trustworthy
- Family-friendly
- Appetizing
- Professional
- Pakistani
- Premium but accessible

Use the BHRZA packaging as the main inspiration.

Color palette:
- Primary brand red: #ED1C2E
- Secondary coral/pink: #F0647D
- Dark charcoal: #202020
- Warm cream: #FFF8F1
- Biscuit/golden accent: #D9A441
- White: #FFFFFF

Use red strategically rather than covering the entire website in red. Combine cream/white backgrounds with red CTAs, headings, highlights and product elements.

Avoid making the website look like a cheap local grocery website.
